# Sortify: Smart Recycling App

A mobile app that tells you **which recycling bin to use** for any item, with colour-coded results and gamified progress tracking.

> Team project (3 students), UX Final Project, Computer Engineering, Universidad Europea de Madrid.

## What it does
- Search for an item and see the correct recycling bin, shown with a clear colour code.
- Track your recycling progress with gamification elements.

## How it was built
Designed with a complete **UX methodology**: user research, wireframes in Figma, and user testing, then implemented as a mobile app in Flutter.

## Tech stack
**Flutter** · **Dart** · **Figma** · UX research · Git/GitHub

## My role
I worked on this project as part of a team of 3, collaborating on the research, the design and the implementation.

## What I learned
- Following a full UX process from user research to testing
- Building a mobile app with Flutter
- Designing for clarity and usability
